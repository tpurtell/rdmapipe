# Releases

## 0.1.0

First stable release. Supports native Linux ARM64 and AMD64 builds with
libibverbs, including DGX Spark and x86_64 RDMA hosts. Includes protocol and
command tests, the manual page, and source under the MIT license.

Release tags use `vMAJOR.MINOR.PATCH`. Published source archives are built
from the tagged commit with `git archive`, and are not replaced after release.
